## VPN-разработка

Отдельное направление — разработка VPN-сервисов и ботов для доступа к сети под ключ.

- Настройка протокола VLESS+Reality на базе Xray-core
- Панели управления (Remnawave, Marzban) — ноды, пользователи, статистика
- Мультилокационная инфраструктура с балансировкой нагрузки
- Telegram-боты для VPN-сервисов: оплата, выдача конфигов, реферальная система
- Telegram Mini App как интерфейс для пользователей
- Backend на Node.js/PostgreSQL под учёт подписок и платежей

Реализованный пример — сервис Astoria: [@AstoriaNetworkBot](https://t.me/AstoriaNetworkBot)
